🕒 Digital Clock using Python and Tkinter
This is a simple Digital Clock GUI application built using Python's tkinter module. It displays the current time and date, updating every second.

🚀 Features
Real-time clock updates every second

Displays current time in HH:MM:SS format

Shows the date in MM/DD/YY format

Simple and clean GUI using tkinter

Background color customization

🧰 Technologies Used
Python 3.x

Tkinter (built-in Python library)

🖥️ How to Run
Make sure Python is installed on your system.

Save the Python code into a file, for example: digital_clock.py.

Run the file using a terminal or IDE:
